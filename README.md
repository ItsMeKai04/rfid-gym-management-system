# Gym Management System with RFID Integration

Web-based Gym Management System built with PHP and MySQL, integrated with RFID for attendance tracking.

## Features
### Admin
- Manage members and trainers
- Assign RFID cards
- View attendance records
- Manage payments

### Trainer
- View attendance related to sessions
- Manage workouts/schedules

### Member
- RFID-based attendance check-in
- View attendance history

## Tech Stack
- PHP
- MySQL
- HTML, CSS
- XAMPP

## How to Run
1. Put the project folder inside `xampp/htdocs`
2. Import the SQL file into phpMyAdmin
3. Update database config in `db.php` (if needed)
4. Run at `http://localhost/your-folder-name`
